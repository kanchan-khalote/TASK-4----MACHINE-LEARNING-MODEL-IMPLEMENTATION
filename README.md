*DESCRIPTION* : 

In this task, the objective is to build and implement a machine learning model using Scikit-Learn to classify or predict outcomes from a given dataset. Machine learning enables systems to automatically learn and improve from experience without being explicitly programmed. This task focuses on understanding the complete workflow of a predictive model — from data preprocessing to model evaluation.

The project demonstrates a Spam Email Detection model as an example. The dataset contains labeled text messages categorized as either spam or ham (non-spam). The text data is converted into numerical form using CountVectorizer, which transforms each message into a set of word frequency features. Then, a Naive Bayes classifier (MultinomialNB) is trained to distinguish between spam and ham messages based on these features.

After training, the model’s performance is evaluated using metrics like accuracy, confusion matrix, and classification report, providing insights into how well the model predicts unseen data. Finally, a sample input message is tested to demonstrate real-time prediction capability.

This task helps in gaining practical experience with Scikit-Learn, understanding text classification, and developing an end-to-end machine learning pipeline — from dataset handling to model deployment-ready output.
